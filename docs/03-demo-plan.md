# 03｜Demo 網頁製作規劃

本文件說明如何把大戶 Junior 的概念做成一個**可互動的 Demo 網頁**，用於提案簡報時現場操作。

👉 線上試玩：<https://yui000130.github.io/SinoPac-DawhoJunior/demo/>

## 1. 目標

- 讓評審在 3–5 分鐘內「親手體驗」三支柱：孩子如何**學得會**理財、**看得懂**自己的資產、**守得住**自己的錢
- 清楚呈現「父母一個動作、孩子即時反應」的親子互動
- 清楚區分「產品功能」與「示範操作」：手機裡只有產品，示範操作集中在控制台
- 不需安裝、不需後端，打開網頁就能操作

## 2. 技術選擇

| 方案 | 優點 | 適合 |
|---|---|---|
| **A. 單一 HTML＋原生 JS（採用）** | 零建置、可直接用 GitHub Pages 部署、檔案少好維護 | 簡報 Demo |
| B. Vite＋React | 元件化、易擴充 | 之後想做成較完整的原型 |

採用 **方案 A**：`index.html`＋`style.css`＋`app.js`，所有資料寫死在前端，狀態存在記憶體中（重新整理即重置）。

### 單手機 / 雙手機規則
- **一般功能介紹** → 只顯示孩子的手機，右側顯示「媽媽同步收到」面板（依查看程度過濾）
- **親子互動功能** → 並排顯示孩子與父母兩支手機，操作一邊、另一邊即時更新
- 孩子在單手機章節按下「請爸媽解鎖」或「遇到可疑的事」時，自動切換為雙手機章節

### 示範控制台
手機畫面中**不放任何「示範／模擬」按鈕**。所有示範操作集中在手機右側的「示範控制台・非產品畫面」（虛線框、灰底），只顯示目前章節相關的按鈕：

| 章節 | 控制台按鈕 |
|---|---|
| 00 開戶簡介 | 下一步、重來、前往 01 |
| 01 零用錢入帳 | 模擬：到了撥款時間（觸發自動撥款） |
| 03 付款前想一想 | 模擬店家掃碼：手搖飲店／便利商店／公車／遊戲點數儲值 |
| 06 我的資產與配息通知 | 模擬：0050 配息 |
| 08 解鎖理財功能 | 模擬：臨櫃完成開通 |
| 09 詐騙攔截與一鍵求助 | 模擬：陌生人轉入 NT$5,000；模擬：網友要小安把錢轉出；模擬：假買家要求補轉 |
| 10 父母查看程度 | 切換小安年齡：12／14／16 歲 |

父母端的「提前撥款」是產品真實會有的功能，留在手機內。

### 操作
- 左側章節列、上方「上一章／下一章」、鍵盤 ← →（簡報筆翻頁鍵 PageUp／PageDown 也可）
- 左下「重新開始示範」把狀態重置為初始值

### 視覺風格
- 沉穩中帶活潑：深藍（#13213F）為主、暖黃（#FBBF24）點綴、藍（#2563EB）為主要按鈕、綠（#0F9F7A）代表儲蓄進度
- 字體：Noto Sans TC
- 圖示使用線條 SVG，不使用 emoji
- **不使用永豐官方 Logo**，並在頁面標示「提案概念展示，非永豐銀行正式產品；畫面中的人物、金額、持股與合作活動皆為示範」

### 示範情境
小安 12 歲國一，每週零用錢 300 元，存 1,800 元買球鞋，媽媽承諾達成加碼 200 元；媽媽也透過永豐金證券的親子帳戶替小安買了 ETF。Demo **預設帳戶已開好**。

## 5. 畫面清單

### 孩子端（大戶 Junior App，底部 5 個分頁：首頁／帳本／目標／學堂／小幫手）
- **首頁**：「可以用的錢」卡（只含零用錢，右上「我的資產 >」）、本週還能花、付款按鈕、「媽媽可以看到：○○」、「遇到可疑的事」、陌生入帳保留／轉帳暫停的橫幅、最近消費、我的功能、成長路線入口
- **我的資產**（由首頁進入）：頂部「我的總資產」；零用錢帳戶（可以花）、存錢目標（存起來的，要用時轉回零用錢）、爸媽幫我存的（長期投資，不能直接花；未綁定時不顯示、未分享時顯示中性文字、分享後顯示總額或持股明細：名稱、代號、股數、示範漲跌幅）、「我想投資」（已開放時）、投資申請狀態、配息通知卡
- **付款流程**：付款碼＋已出示載具 →（必要時）付款前想一想 → 付款成功（顯示載具帶入品項）→ 需要／想要＋選填備註（只有孩子看得到）→ 完成；封鎖類別與單日上限會擋下
- **帳本**：未標記提示、分類花費、消費明細（載具品項可展開、未標記可補標、手動補記）、需要 vs 想要、每週回顧
- **存錢目標**（含慶祝畫面）
- **理財學堂**：8 課課程列表、課程內容與測驗、合作活動推薦
- **AI 理財小幫手**：5 題預設問答＋「遇到可疑的事」
- **成長路線**：零用錢管理 → 理財學堂 → 看懂我的資產 → 解鎖理財功能 →（未來延伸）18 歲成年禮
- **彈出層**：鎖住功能說明、解鎖成功、手動補記、我想投資、網友訊息、交易當下提醒（人頭帳戶／假買家）、遇到可疑的事（選狀況）、求助完成（含 165 反詐騙諮詢專線）、通知 toast

### 父母端（DAWHO › Junior，底部 4 個分頁：總覽／零用錢／獎勵／設定）
- **總覽**（只放現況，順序固定）：①求助與防詐警示、陌生入帳保留、解鎖申請、投資申請 ②小安可以用的錢、本月花費、目標進度 ③消費（依查看程度呈現）④每週回顧 ⑤給小安一點鼓勵
- **求助通知卡**：小安選的狀況＋「請先陪伴，不要責備」＋「打電話給小安」＋「聯繫永豐客服」＋「處理完畢，解除轉帳暫停」
- **零用錢**：金額、頻率、自動撥款、提前撥款
- **獎勵**：獎勵規則、鼓勵、近期動態（依查看程度過濾）
- **設定**：查看程度（依年齡自動預設＋三選一）、投資分享與投資權限、單日消費上限、封鎖消費類別、永豐防詐守護
- 不在總覽時，若有防詐通知，頂部顯示「有 ○ 則防詐通知」橫條

## 6. 狀態模型

兩支手機共用**同一份狀態**，這是「操作一邊、另一邊即時反應」的關鍵。

```js
const state = {
  // 示範控制
  ch: 'allow',               // 目前章節
  kidView: 'home',           // 孩子端目前畫面
  parView: 'allowance',      // 父母端目前畫面
  openStep: 0,               // 00 開戶簡介的步驟

  // 帳戶
  balance: 480,              // 可以用的錢（不含保留中的陌生入帳）
  weekSpent: 110,
  todaySpent: 0,
  todayReminders: 0,         // 今天已出現的付款前提醒次數（上限 2）
  allowance: 300,
  freq: '每週',
  auto: true,

  // 存錢目標
  goal: { name: '球鞋基金', saved: 1500, target: 1800 },
  goalsDone: 0,

  // 消費紀錄（自動記帳）
  tx: [
    { name: '便利商店', amt: 85, cat: '飲食', tag: 'need',   // tag 可為 null（未標記）
      source: 'carrier',                       // 'card' 刷卡 | 'carrier' 載具 | 'manual' 手動補記
      items: [['飲料', 35], ['麵包', 50]],      // 載具帶入的品項明細（選填）
      note: '早餐',                             // 孩子選填備註，只有孩子看得到
      time: '週一 07:40' },
    // ...
  ],
  pay: { step: 'code', m: null, note: '', remind: false },   // code → confirm / blocked → tag → done

  // 父母獎勵規則
  rules: { goal: true, noOver: false, lesson: false },

  // 功能解鎖：locked → pending → open
  //                         └→ branch → booked → open（需臨櫃）
  feat: { transfer: 'locked', deposit: 'locked', fx: 'locked', invest: 'locked' },

  // 看得懂：我的資產
  hasLinkedSecurities: true, // 父母是否綁定證券親子帳戶（示範情境預設有）
  shareInvest: false,        // 父母是否開啟「讓孩子看見我替他買的投資」
  shareLevel: 'total',       // 'total' 只看總額 | 'detail' 持股明細
  investReqs: [],            // 孩子的投資申請：{ code, shares, reason, status: 'pending' | 'sent' | 'declined' }
  dividend: null,            // 模擬配息通知

  // 守得住
  dayLimit: 1500,
  blocked: { game: true, crypto: true, overseas: false },
  heldIncoming: null,        // 保留中的陌生入帳：null | { amt }
  transferAlert: null,       // 交易當下提醒：null | 'muleMsg' | 'mule' | 'fakeBuyer'
  helpRequested: false,      // 是否送出求助
  helpReason: '',            // 孩子選的狀況（選填）
  outboundFrozen: false,     // 轉帳是否暫停（刷卡、手機付款不受影響）
  parAlerts: [],             // 父母端警示卡

  // 成長機制：父母查看程度（依年齡分層）
  childAge: 12,              // 示範用：12 / 14 / 16；第 09 章自動切為 16
  viewLevel: 'detail',       // 'detail' 完整明細 | 'store' 店家與金額 | 'monthly' 每月分類總額

  // 通知
  feed: [],                  // 同步給父母的事件：{ type, t, txId? }
  kidToast: '',
  parToast: '',
};
```

### 渲染方式
- 所有操作都透過 `set(patch)` 更新狀態，再呼叫 `render()` 重繪兩支手機
- 通知 toast 以 `setTimeout` 約 3 秒後自動消失
- 「重新開始示範」按鈕把狀態重置為初始值

### 解鎖流程
```js
function requestFeat(id) {
  state.feat[id] = 'pending';
  // 若目前是單手機章節，自動切換到「解鎖理財功能」章節（雙手機）
}

function approve(id) {
  if (isOnline(id)) state.feat[id] = 'open';   // 線上開通 → 解鎖動畫
  else state.feat[id] = 'branch';              // 需臨櫃 → 預約分行 → 控制台模擬臨櫃完成
}
// 「自己投資」：已綁定證券親子帳戶 → 線上開通；沒有證券帳戶 → 預約分行
```

### 達成目標與自動加碼
```js
function depositGoal() {
  state.balance -= 100;
  state.goal.saved += 100;
  if (state.goal.saved >= state.goal.target && state.rules.goal) {
    state.balance += 200;      // 媽媽加碼
    // 顯示慶祝畫面
  }
}
```

### 我的資產、投資權限與配息
```js
const totalAssets = balance + goal.saved + (hasLinkedSecurities && shareInvest ? investTotal : 0);

function setInvestPerm(k) {    // 'view' 只能看 | 'self' 可以自己投資
```

### 陌生入帳先保留、交易當下提醒與一鍵求助
```js
function simHeld() {           // 控制台：陌生人轉入 5,000
  set({ heldIncoming: { amt: 5000 } });   // 不加進 balance
  // 孩子首頁：「有一筆陌生轉入 NT$5,000 待爸媽確認」；父母總覽：確認是認識的人／退回並通報
}

function muleTry() {           // 網友要小安轉出 → 小安照做
  set({ transferAlert: 'mule' });         // 「這筆錢還沒入帳，不能轉出」＋取消／遇到可疑的事
}

function simFakeBuyer() {      // 控制台：假買家要求「驗證帳戶」「補轉」300 元（小額）
  set({ transferAlert: 'fakeBuyer' });    // 只提醒不阻擋；取消轉帳／我確定要繼續，父母同步收到通知
}

function requestHelp(reason) { // 「遇到可疑的事」，reason 選填
  set({ helpRequested: true, helpReason: reason, outboundFrozen: true });
  // 只暫停轉帳；父母收到「請先陪伴，不要責備」；單手機章節自動切換到章節 09
}
```

### 父母查看程度與通知過濾
```js
const DEFAULT_LEVEL = age => age <= 12 ? 'detail' : age <= 15 ? 'store' : 'monthly';

function setAge(age) {
  set({ childAge: age, viewLevel: DEFAULT_LEVEL(age) });
}

// 同步事件依查看程度過濾：每月分類總額時不顯示單筆消費；防詐與求助永遠顯示
const visibleFeed = () => state.feed.filter(f => state.viewLevel !== 'monthly' || f.type !== 'spend');
// feed type：spend | goal | lesson | request | help | security | review | parent
```

- 同一份消費紀錄依查看程度呈現：`detail` 逐筆列出（含載具品項與需要／想要標記）；`store` 逐筆只顯示店家、金額與時間；`monthly` 只顯示本月各分類總額
- 單手機章節的「媽媽同步收到」面板與父母端「獎勵」頁的動態都套用同一個過濾
- 孩子自己寫的備註在任何查看程度都不會顯示給父母
- 孩子端首頁顯示「媽媽可以看到：每筆明細／每筆的店家與金額／每月分類總額」，隨設定即時改變

## 8. 資料內容（寫死在前端）

- **學堂課程（8 課）**：什麼是預算？／需要 vs 想要／定存與利息／複利：讓錢自己長大／爸媽幫我買的是什麼？認識股票與 ETF／風險與分散／防詐：保證獲利都是騙人的／假買家詐騙：真正的買家不會要你操作網銀
