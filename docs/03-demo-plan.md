# 03｜Demo 網頁製作規劃

本文件說明如何把大戶 Junior 的概念做成一個**可互動的 Demo 網頁**，用於提案簡報時現場操作。

👉 線上試玩：<https://yui000130.github.io/SinoPac-DawhoJunior/demo/>

## 1. 目標

- 讓評審在 3–5 分鐘內「親手體驗」三支柱：孩子如何**學得會**理財、**看得懂**自己的資產、**守得住**自己的錢
- 清楚呈現「父母一個動作、孩子即時反應」的親子互動
- 不需安裝、不需後端，打開網頁就能操作

## 2. 技術選擇

| 方案 | 優點 | 適合 |
|---|---|---|
| **A. 單一 HTML＋原生 JS（採用）** | 零建置、可直接用 GitHub Pages 部署、檔案少好維護 | 簡報 Demo |
| B. Vite＋React | 元件化、易擴充 | 之後想做成較完整的原型 |

採用 **方案 A**：`index.html`＋`style.css`＋`app.js`，所有資料寫死在前端，狀態存在記憶體中（重新整理即重置）。

## 3. 版面設計

以 **1440×900 寬螢幕**（筆電接投影）為舞台尺寸，並依視窗大小等比縮放。

```

│ 大戶 Junior         │ [上一章]  第一幕・學得會 01 章節標題 [下一章] │
│                    │                                          │
│ 第一幕・學得會       │   ┌──────────┐      ┌──────────┐         │
│  01 零用錢自動入帳   │   │ 小安的手機 │      │ 媽媽的手機 │         │
│  ...               │   │ 大戶Junior│      │ DAWHO    │         │
│ 第二幕・看得懂       │   │          │      │ › Junior │         │
│  06 我的資產…       │   └──────────┘      └──────────┘         │
│ 第三幕・守得住       │                                          │

│ [重新開始示範]      │                                          │
└────────────────────┴──────────────────────────────────────────┘
```

### 單手機 / 雙手機規則
- **一般功能介紹** → 只顯示孩子的手機，右側顯示「媽媽同步收到」面板
- **親子互動功能** → 並排顯示孩子與父母兩支手機，操作一邊、另一邊即時更新
- 孩子在單手機章節按下「請爸媽解鎖」或「我好像被騙了」時，自動切換為雙手機章節

### 操作
- 左側章節列、上方「上一章／下一章」、鍵盤 ← →（簡報筆翻頁鍵 PageUp／PageDown 也可）
- 左下「重新開始示範」把狀態重置為初始值

### 視覺風格
- 沉穩中帶活潑：深藍（#13213F）為主、暖黃（#FBBF24）點綴、藍（#2563EB）為主要按鈕、綠（#0F9F7A）代表儲蓄進度
- 字體：Noto Sans TC
- 圖示使用線條 SVG，不使用 emoji
- **不使用永豐官方 Logo**，並在頁面標示「提案概念展示，非永豐銀行正式產品；畫面中的人物、金額、持股與合作活動皆為示範」

### 示範情境
小安 12 歲國一，每週零用錢 300 元，存 1,800 元買球鞋，媽媽承諾達成加碼 200 元；媽媽也透過永豐金證券的親子帳戶替小安買了 ETF。

## 5. 畫面清單

### 孩子端（大戶 Junior App，底部 5 個分頁：首頁／帳本／目標／學堂／小幫手）
- **首頁**：「我的全部資產」卡（零用錢＋存錢目標＋爸媽幫我存的）、本週還能花、付款按鈕、「媽媽可以看到：○○」小字、「我好像被騙了」次要按鈕、最近消費、我的功能、成長路線入口
- **我的資產**（由首頁資產卡進入）：零用錢帳戶、存錢目標、爸媽幫我存的（唯讀；未開啟分享時顯示鎖住；開啟後依父母選擇顯示總額或持股明細，每檔含「這是什麼？」按鈕）、配息通知卡、「示範數值，非即時股價」標示
- **付款流程**：付款碼＋已出示載具 → 模擬店家掃碼 → 付款前想一想 → 付款成功（顯示載具帶入品項）→ 需要／想要＋選填備註（只有孩子看得到）→ 完成；封鎖類別與單日上限會擋下
- **帳本**：分類花費、消費明細（載具消費可展開品項、手動補記按鈕）、需要 vs 想要、每週回顧
- **存錢目標**（含慶祝畫面）
- **理財學堂**：8 課課程列表、課程內容與測驗、合作活動推薦
- **AI 理財小幫手**：5 題預設問答＋「我好像被騙了」按鈕
- **成長路線**：零用錢管理 → 理財學堂 → 看懂我的資產 → 解鎖理財功能 →（未來延伸）18 歲成年禮
- **彈出層**：鎖住功能說明、解鎖成功、手動補記、交易當下提醒（人頭帳戶／假買家）、一鍵求助（含 165 反詐騙諮詢專線）、通知 toast

### 父母端（DAWHO › Junior，底部 4 個分頁：總覽／零用錢／獎勵／安全）
- **總覽**：求助通知卡與防詐警示（最上方）、解鎖申請、餘額與花費、每週回顧、**依查看程度呈現的消費資訊**、投資分享（開關＋只看總額／持股明細＋模擬配息）、查看程度（示範用年齡切換＋三選一設定）、鼓勵；依目前章節把相關區塊排在前面
- **求助通知卡**：「小安主動向你求助，請先陪伴，不要責備」＋「打電話給小安」＋「聯繫永豐客服」＋「處理完畢，解除轉出暫停」
- **零用錢設定**
- **獎勵與鼓勵**

## 6. 狀態模型

兩支手機共用**同一份狀態**，這是「操作一邊、另一邊即時反應」的關鍵。

```js
const state = {
  // 示範控制
  ch: 'allow',               // 目前章節
  kidView: 'home',           // 孩子端目前畫面
  parView: 'allowance',      // 父母端目前畫面

  // 帳戶
  balance: 480,
  weekSpent: 110,
  todaySpent: 0,
  allowance: 300,
  freq: '每週',
  auto: true,

  // 存錢目標
  goal: { name: '球鞋基金', saved: 1500, target: 1800 },
  goalsDone: 0,

  // 消費紀錄（自動記帳）
  tx: [
    { name: '便利商店', amt: 85, cat: '飲食', tag: 'need',
      source: 'carrier',                       // 'card' 刷卡 | 'carrier' 載具 | 'manual' 手動補記
      items: [['飲料', 35], ['麵包', 50]],      // 載具帶入的品項明細（選填）
      note: '早餐',                             // 孩子選填備註，只有孩子看得到
      time: '週一 07:40' },
    // ...
  ],
  pay: { step: 'code', m: null, note: '' },    // code → confirm / blocked → tag → done
  reviewPick: null,
  manual: null,                                 // 手動補記草稿

  // 父母獎勵規則
  rules: { goal: true, noOver: false, lesson: false },
  cheer: '',

  // 學堂
  lessonsDone: [],
  lessonOpen: null,

  // 功能解鎖：locked → pending → open
  //                         └→ branch → booked → open（需臨櫃）
  feat: { transfer: 'locked', deposit: 'locked', fx: 'locked', fund: 'locked', stock: 'locked' },

  // 看得懂：我的資產
  shareInvest: false,        // 父母是否開啟「讓孩子看見我替他買的投資」
  shareLevel: 'total',       // 'total' 只看總額 | 'detail' 持股明細
  dividend: null,            // 模擬配息通知

  // 守得住
  dayLimit: 1500,
  blocked: { game: true, crypto: true, overseas: false },
  transferAlert: null,       // 交易當下提醒情境：null | 'mule' | 'fakeBuyer'
  helpRequested: false,      // 是否按下一鍵求助
  outboundFrozen: false,     // 帳戶轉出是否暫停
  parAlerts: [],             // 父母端警示卡

  // 成長機制：父母查看程度（依年齡分層）
  childAge: 12,              // 示範用：可切換 12 / 14 / 16
  viewLevel: 'detail',       // 'detail' 完整明細 | 'store' 店家與金額 | 'monthly' 每月分類總額

  // 通知
  feed: [],                  // 同步給父母的事件
  kidToast: '',
  parToast: '',
};
```

### 渲染方式
- 所有操作都透過 `set(patch)` 更新狀態，再呼叫 `render()` 重繪兩支手機
- 通知 toast 以 `setTimeout` 約 3 秒後自動消失
- 「重新開始示範」按鈕把狀態重置為初始值

## 7. 關鍵互動邏輯

### 付款前目標提醒
```js
// 假設每週存 100 元，換算花費會讓目標延後幾天
const delayDays = Math.max(1, Math.ceil(amount / (100 / 7)));
```

### 解鎖流程
```js
function requestFeat(id) {
  state.feat[id] = 'pending';
  // 若目前是單手機章節，自動切換到「解鎖理財功能」章節（雙手機）
}

function approve(id) {
  if (featOf(id).online) state.feat[id] = 'open';   // 線上開通 → 解鎖動畫
  else state.feat[id] = 'branch';                    // 需臨櫃 → 預約分行
}
```

### 達成目標與自動加碼
```js
function depositGoal() {
  state.balance -= 100;
  state.goal.saved += 100;
  if (state.goal.saved >= state.goal.target && state.rules.goal) {
    state.balance += 200;      // 媽媽加碼
    // 顯示慶祝畫面
  }
}
```

### 我的資產與配息
```js
function toggleShare() {
  set({ shareInvest: !state.shareInvest });
  // 開啟時孩子端 toast：「爸媽開啟了投資分享」
}

function simDividend() {
  set({ dividend: { code: '0050', amt: 10 } });   // 示範數值
  // 已開啟分享 → 孩子端 toast：「你的 0050 配息了！」並提示學堂「複利」課
  // 未開啟分享 → 只提醒父母「開啟分享後小安才會收到通知」
}
```

### 交易當下提醒與一鍵求助
```js
const LARGE_TRANSFER = 3000;   // 示範用的大額門檻

function simMule() {           // 陌生人轉入 5,000 後要求轉出（大額）
  // 大額 → 永豐防詐守護暫停轉出；孩子端跳出提醒，父母端出現警示卡
  set({ transferAlert: 'mule' });
}

function simFakeBuyer() {      // 假買家要求「驗證帳戶」「補轉」300 元（小額）
  // 小額 → 只提醒不阻擋；孩子可「取消轉帳」或「我確定要繼續」，父母同步收到通知
  set({ transferAlert: 'fakeBuyer' });
}

function requestHelp() {
  set({ helpRequested: true, outboundFrozen: true });
  // 父母端收到「請先陪伴，不要責備」；若目前為單手機章節，自動切換到章節 09
}
```

### 父母查看程度（年齡分層）
```js
const DEFAULT_LEVEL = age => age <= 12 ? 'detail' : age <= 15 ? 'store' : 'monthly';

function setAge(age) {
  set({ childAge: age, viewLevel: DEFAULT_LEVEL(age) });
}
```

- 父母端「總覽」的「查看程度」區塊，含示範用的「切換年齡：12／14／16 歲」按鈕，以及父母可手動調整的三選一設定
- 同一份消費紀錄依查看程度呈現：`detail` 逐筆列出（含載具品項與需要／想要標記）；`store` 逐筆只顯示店家、金額與時間；`monthly` 只顯示本月各分類總額
- 孩子自己寫的備註在任何查看程度都不會顯示給父母
- 防詐警示與求助通知不受查看程度影響
- 孩子端首頁顯示一行小字「媽媽可以看到：每筆明細／每筆的店家與金額／每月分類總額」，隨設定即時改變

## 8. 資料內容（寫死在前端）

- **模擬店家**：手搖飲店 65（載具：珍珠奶茶）、便利商店 85（載具：飲料 35＋麵包 50）、公車 15、遊戲點數儲值 300（封鎖類別）
- **手動補記範例**：夜市雞排 NT$70
- **持股**：0050 × 3 股、00858 × 10 股，市值各 NT$500、配息 NT$10，**皆為示範數值，畫面註明「示範數值，非即時股價」**
- **學堂課程（8 課）**：什麼是預算？／需要 vs 想要／定存與利息／複利：讓錢自己長大／爸媽幫我買的是什麼？認識股票與 ETF／風險與分散／防詐：保證獲利都是騙人的／假買家詐騙：真正的買家不會要你操作網銀
- **AI 小幫手預設問題（5 題）**：為什麼要存錢？／什麼是 ETF？／爸媽幫我買的股票會變多嗎？／網友說借我的帳戶收款可以賺 500 元，可以嗎？（警示）／買家說要我操作網銀驗證帳戶，可以嗎？（警示）
- **合作活動**：以 `[合作單位]` 佔位，待確定後填入
- **預約分行**：以 `[分行名稱]` 佔位

## 10. 部署

使用 **GitHub Pages**：
1. 將 repo 推上 GitHub
2. Settings → Pages → Source 選擇 `Deploy from a branch`、`main` 分支、`/ (root)` 資料夾
3. 網址為 `https://<帳號>.github.io/<repo>/demo/`，簡報時直接開啟

## 11. 簡報操作建議

- 完整流程約 5 分鐘；精簡版（約 3 分鐘）：01 → 03 → 06 → 09 → 10
- 每次示範前按「重新開始示範」
- 最有記憶點的三個瞬間：
  1. 付款前「目標會晚 5 天達成」的提醒
  2. 媽媽打開投資分享，小安第一次看見「爸媽幫我存的」，接著收到配息通知
  3. 小安按下「我好像被騙了」，媽媽收到「請先陪伴，不要責備」
