# 03｜Demo 網頁製作規劃

本文件說明如何把大戶 Junior 的概念做成一個**可互動的 Demo 網頁**，用於提案簡報時現場操作。

## 1. 目標

- 讓評審在 2–5 分鐘內「親手體驗」孩子如何透過行為學會理財
- 清楚呈現「父母一個動作、孩子即時反應」的親子互動
- 不需安裝、不需後端，打開網頁就能操作

## 2. 技術選擇

| 方案 | 優點 | 適合 |
|---|---|---|
| **A. 單一 HTML＋原生 JS（建議）** | 零建置、可直接用 GitHub Pages 部署、檔案少好維護 | 簡報 Demo |
| B. Vite＋React | 元件化、易擴充 | 之後想做成較完整的原型 |

建議採用 **方案 A**：`index.html`＋`style.css`＋`app.js`，所有資料寫死在前端，狀態存在記憶體中（重新整理即重置）。

## 3. 版面設計

建議以 **1440×900 寬螢幕**（筆電接投影）為主要尺寸。

```
┌────────────────┬──────────────────────────────────────┐
│ 大戶 Junior     │        章節標題   [單手機 / 雙手機]     │
│                │                                      │
│ 01 零用錢入帳   │   ┌──────────┐      ┌──────────┐     │
│ 02 孩子的首頁   │   │ 小安的手機 │      │ 媽媽的手機 │     │
│ 03 付款前想一想 │   │ 大戶Junior│      │ DAWHO    │     │
│ ...            │   │          │      │ › Junior │     │
│ 10 成長路線     │   └──────────┘      └──────────┘     │
│                │                                      │
│ 試試看：…       │   （一般功能只顯示左邊的孩子手機）       │
│ [重新開始示範]  │                                      │
└────────────────┴──────────────────────────────────────┘
```

### 單手機 / 雙手機規則
- **一般功能介紹** → 只顯示孩子的手機
- **親子互動功能** → 並排顯示孩子與父母兩支手機，操作一邊、另一邊即時更新
- 孩子在單手機章節中按下「請爸媽解鎖」時，自動切換為雙手機

### 視覺風格
- 沉穩中帶活潑：深藍（#13213F）為主、暖黃（#FBBF24）點綴、藍（#2563EB）為主要按鈕、綠（#0F9F7A）代表儲蓄進度
- 字體：Noto Sans TC
- 圖示使用線條 SVG，不使用 emoji
- **不使用永豐官方 Logo**，並在頁面標示「提案概念展示，非永豐銀行正式產品」

## 5. 畫面清單

### 孩子端（大戶 Junior App，底部 5 個分頁）
- 首頁（含付款入口、我的功能、成長路線入口）
- 付款流程：選擇商品 → 付款前想一想 → 付款條碼 → 需要／想要 → 完成
- 帳本（含每週回顧）
- 存錢目標（含慶祝畫面）
- 理財學堂（課程列表、課程內容與測驗、活動推薦）
- AI 理財小幫手
- 成長路線（從首頁進入）
- 彈出層：鎖住功能說明、解鎖成功、防詐提醒、通知 toast

### 父母端（DAWHO › Junior，底部 4 個分頁）
- 總覽（防詐警示、解鎖申請、餘額與花費、每週回顧、鼓勵、最近消費）
- 零用錢設定
- 獎勵與鼓勵
- 安全設定

## 6. 狀態模型

兩支手機共用**同一份狀態**，這是「操作一邊、另一邊即時反應」的關鍵。

```js
const state = {
  // 示範控制
  chapter: 'allow',          // 目前章節
  kidView: 'home',           // 孩子端目前畫面
  parentView: 'allowance',   // 父母端目前畫面

  // 帳戶
  balance: 480,
  weekSpent: 110,
  allowance: 300,
  frequency: '每週',
  autoPay: true,

  // 存錢目標
  goal: { name: '球鞋基金', saved: 1500, target: 1800 },
  goalsDone: 0,

  // 消費紀錄（自動記帳）
  transactions: [
    { name: '午餐', amount: 80, category: '飲食', tag: 'need' },
    // ...
  ],
  payFlow: { step: 'choose', item: null }, // choose → think → code → tag → done / blocked
  weeklyReview: null,

  // 父母獎勵規則
  rewards: { goalBonus: true, noOverspend: false, lessonBonus: false },
  cheer: '',

  // 學堂
  lessonsDone: [],
  openLesson: null,

  // 功能解鎖：locked → pending → open
  //                         └→ branch → booked → open（需臨櫃）
  features: { transfer: 'locked', deposit: 'locked', fx: 'locked', fund: 'locked', stock: 'locked' },

  // 安全
  dailyLimit: 1500,
  blocked: { game: true, crypto: true, overseas: false },
  scamAlert: false,

  // 通知
  kidToast: '',
  parentToast: '',
};
```

### 渲染方式
- 所有操作都透過 `setState(patch)` 更新狀態，再呼叫 `render()` 重繪兩支手機
- 通知 toast 以 `setTimeout` 約 3 秒後自動消失
- 「重新開始示範」按鈕把狀態重置為初始值

```js
function setState(patch) {
  Object.assign(state, patch);
  render();
}
```

## 7. 關鍵互動邏輯

### 付款前目標提醒
```js
// 假設每週存 100 元，換算花費會讓目標延後幾天
const delayDays = Math.max(1, Math.ceil(item.amount / (100 / 7)));
```

### 解鎖流程
```js
function requestUnlock(id) {
  state.features[id] = 'pending';
  // 若目前是單手機章節，自動切換到「解鎖理財功能」章節（雙手機）
}

function approve(id) {
  if (FEATURES[id].online) state.features[id] = 'open';   // 線上開通 → 解鎖動畫
  else state.features[id] = 'branch';                     // 需臨櫃 → 預約分行
}
```

### 達成目標與自動加碼
```js
function depositToGoal() {
  state.balance -= 100;
  state.goal.saved += 100;
  if (state.goal.saved >= state.goal.target && state.rewards.goalBonus) {
    state.balance += 200;      // 媽媽加碼
    showCelebration();
  }
}
```

## 8. 資料內容（寫死在前端）

- **付款商品**：珍珠奶茶 65、筆記本 45、公車 15、遊戲點數 300（封鎖類別）
- **學堂課程**：7 課，每課含內容、一題測驗、答對／答錯回饋，並對應一項可解鎖功能
- **AI 問答**：4 組預設問答，其中 1 組為防詐警示
- **合作活動**：以 `[合作單位]` 佔位，待確定後填入
- **預約分行**：以 `[分行名稱]` 佔位

## 10. 部署

使用 **GitHub Pages**：
1. 將 `demo/` 推上 repo
2. Settings → Pages → Source 選擇 `main` 分支、`/demo` 或 `/root` 資料夾
3. 取得公開網址，簡報時直接開啟

## 11. 簡報操作建議

- 建議順序：01 → 03 → 05 → 08 → 09 → 10（約 3 分鐘），時間充裕再補 04、06、07
- 每次示範前按「重新開始示範」
- 最有記憶點的三個瞬間：
  1. 付款前「目標會晚 5 天達成」的提醒
  2. 小安申請解鎖、媽媽按下同意、孩子端跳出解鎖動畫
  3. 防詐模擬時，兩支手機同時跳出警示
