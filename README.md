# 大戶 Junior（DAWHO Junior）

> **大戶 Junior：讓孩子學得會、看得懂、守得住自己的錢。**
>
> 「大戶 Junior」是一份向永豐銀行提出的金融創新提案：把永豐數位帳戶「大戶 DAWHO」延伸到 7–17 歲的未成年族群，結合永豐的銀證整合與防詐優勢，讓孩子從管理零用錢開始，看懂爸媽替自己存的資產，並在數位世界中守住自己的錢。

> ⚠️ 本專案為學生提案的概念展示，**並非永豐銀行正式產品**。文件與 Demo 中的人物、金額、持股、合作活動皆為示範。

---

## 一句話說明

不靠利息優惠或消費回饋，而是賣「**讓孩子養成理財觀念**」的價值：

- **父母**因為「安全、看得見、有教育意義」而願意開戶
- **孩子**因為「自主、成就感、被信任」而持續使用
- **永豐**提早接觸下一代客群，把父母替孩子開的帳戶，轉化為培養未來客戶的管道

## 核心設計原則

1. **越簡單越好**：核心只有零用錢、手機支付、自動記帳、存錢目標
2. **利益由父母決定**：獎勵、解鎖、權限全部由父母設定，銀行只提供工具，不靠利息或回饋讓利
3. **知識自由學，真錢要把關**：理財學堂隨時可看；動用真錢的理財功能需父母開啟
4. **安全是底線**：防詐警示由銀行預設開啟，父母無法關閉

## 功能總覽

| 支柱 | 解決的問題 | 功能 |
|---|---|---|
| 📘 學得會 | 孩子缺乏理財習慣 | 零用錢自動入帳、手機支付＋載具自動記帳（可手動補記）、付款前目標提醒、需要／想要標記、帳本與每週回顧、存錢目標＋父母獎勵、理財學堂、AI 理財小幫手 |
| 👀 看得懂 | 孩子名下有資產，自己卻不知道 | 我的資產：唯讀顯示爸媽透過永豐親子帳戶替孩子買的投資、配息通知、對應學堂說明；父母可開放孩子自己投資（每筆經父母確認） |
| 🛡️ 守得住 | 兒少詐騙快速增加 | 轉帳給朋友預設鎖住、陌生入帳先保留、封鎖消費類別、交易當下提醒、一鍵求助「遇到可疑的事」 |
| 成長機制 | — | 父母解鎖理財功能、父母查看程度依年齡分層 |

父母端整合在父母原本的 **DAWHO App** 中（新增「Junior」分頁），不需另外下載。

**父母查看程度依年齡分層**：7–12 歲看完整明細（含品項）、13–15 歲看每筆的店家與金額、16–17 歲只看每月分類總額＋異常提醒。系統自動預設，父母只需一個設定；防詐警示不受影響，孩子自己寫的備註也不會分享給父母。

## 拉新與黏著度

- **拉新**：以「家庭」取代「讓利」。從既有大戶家長開始推廣，並透過孩子反向帶進新家長
- **黏著**：孩子為了理財天天打開 Junior；父母為了看見孩子成長常打開 DAWHO，一個功能提高兩代用戶的黏著度

## 延伸想法（未來，不在 Demo 中）

- **旅行基金**：結合永豐外幣優勢，存錢目標可設為外幣
- **18 歲成年禮**：一鍵轉為正式大戶＋大戶投，接手爸媽替自己存的投資

## Demo

👉 **線上試玩：<https://yui000130.github.io/SinoPac-DawhoJunior/demo/>**

（也可以直接下載本 repo，雙擊 `demo/index.html` 離線開啟）

Demo 以「章節」方式呈現情境：一般功能顯示孩子的單一手機，親子互動功能則並排顯示孩子與父母兩支手機，操作一邊、另一邊即時反應。設計規劃見 [docs/03-demo-plan.md](docs/03-demo-plan.md)。

操作方式：
- 點左側章節，或用上方「上一章／下一章」、鍵盤 ← →（簡報筆翻頁鍵也可）切換
- 手機畫面只有產品功能；「模擬店家掃碼」「模擬配息」「切換年齡」等示範操作都在右側的「示範控制台」
- 「00 開戶簡介」為選用章節，預設從 01 開始；最後的「終章」總結對永豐的價值
- 每次示範前按左下「重新開始示範」
- 完整流程約 5 分鐘；精簡版（約 3 分鐘）：01 → 03 → 06 → 09 → 10 → 終章
- 畫面會依螢幕大小等比縮放，適合筆電接投影
