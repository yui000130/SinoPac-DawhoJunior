# 大戶 Junior（DAWHO Junior）

> **孩子的第一個帳戶，父母的第一個理財教具。**

「大戶 Junior」是一份向永豐銀行提出的金融創新提案：把永豐數位帳戶「大戶 DAWHO」已驗證成功的經營模式，往下延伸到 7–17 歲的未成年族群，讓孩子從管理零用錢開始，**透過日常行為學會理財**，並在 18 歲時無縫成為正式的大戶用戶。

> ⚠️ 本專案為學生提案的概念展示，**並非永豐銀行正式產品**。文件與 Demo 中的人物、金額、合作活動皆為示範。

---

## 一句話說明

不靠利息優惠或消費回饋，而是賣「**讓孩子養成理財觀念**」的價值：

- **父母**因為「安全、看得見、有教育意義」而願意開戶
- **孩子**因為「自主、成就感、被信任」而持續使用
- **永豐**提早接觸下一代客群，18 歲時一鍵轉為正式大戶

## 核心設計原則

1. **越簡單越好**：核心只有零用錢、手機支付、自動記帳、存錢目標
2. **利益由父母決定**：獎勵、解鎖全部由父母設定，銀行只提供工具，不讓利
3. **知識自由學，真錢要把關**：理財學堂隨時可看；動用到錢的理財功能需父母開啟
4. **安全是底線**：防詐警示由銀行預設開啟，父母無法關閉

## 功能總覽

| 層級 | 功能 | 狀態 |
|---|---|---|
| 🌱 開戶即有 | 零用錢自動入帳、手機支付＋自動記帳、付款前目標提醒、需要／想要標記、帳本與每週回顧、存錢目標＋父母獎勵、AI 理財小幫手、理財學堂 | 直接使用 |
| 🔒 父母解鎖 | 轉帳給朋友、定存、外幣存款、基金定期定額、小額存股 | 畫面上顯示但鎖住，孩子可申請 |
| 🎓 18 歲成年禮 | 一鍵轉為正式大戶帳戶＋證券帳戶、理財結業證書、第一次真實投資 | 倒數顯示 |

父母端整合在父母原本的 **DAWHO App** 中（新增「Junior」分頁），不需另外下載。

## Demo

👉 **線上試玩：<https://yui000130.github.io/SinoPac-DawhoJunior/demo/>**

（也可以直接下載本 repo，雙擊 `demo/index.html` 離線開啟）

Demo 以「章節」方式呈現 10 個情境：一般功能顯示孩子的單一手機，親子互動功能（零用錢入帳、獎勵、解鎖、防詐）則並排顯示孩子與父母兩支手機，操作一邊、另一邊即時反應。設計規劃見 [docs/03-demo-plan.md](docs/03-demo-plan.md)。

操作方式：
- 點左側章節，或用上方「上一章／下一章」、鍵盤 ← →（簡報筆翻頁鍵也可）切換
- 每次示範前按左下「重新開始示範」
- 建議簡報順序：01 → 03 → 05 → 08 → 09 → 10（約 3 分鐘）
- 畫面會依螢幕大小等比縮放，適合筆電接投影
